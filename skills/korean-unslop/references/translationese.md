# 번역투 대안표

국립국어원 『새국어생활』, 신문 교열 칼럼(우리말 바루기), 대학 언론 교열 기사, 기술 문서 작성 가이드에 실린 예를 모았다. 국립국어원은 번역투가 어법상 틀린 것은 아니고, 더 자연스러운 표현이 있으면 그것을 쓰라고 권한다. 이 표도 "금지 목록"이 아니라 "먼저 시도해 볼 대안"이다.

원칙: 대부분 조사 하나나 동사 하나로 줄어든다. 줄였는데 뜻이 그대로면 줄인 쪽을 쓴다.

## 조사·후치사

| 번역투 | 대안 | 예 |
|---|---|---|
| ~에 있어서 | ~에서, ~할 때 | 승진에 있어서 차별 → 승진에서 차별 / 설정에 있어서 주의가 필요 → 설정할 때 주의해야 |
| ~을/를 통해 | ~로, ~을 써서, ~해서, 생략 | 이 기능을 통해 모을 수 있다 → 이 기능으로 모을 수 있다 / 이번 기회를 통해 → 이번 기회에 |
| ~에 대한/대해/관한/관하여 | 목적격 조사, ~에 필요한 | 오류에 관하여 대비했다 → 오류를 대비했다 / 검색 의도에 대한 분석이 먼저 → 검색 의도를 먼저 분석 |
| ~의 경우 | ~는, ~때, 생략 | 제 경우엔 → 저는 / 어떤 경우 → 어떤 때 |
| ~에 의해/의하여 | 행위자를 주어로 | 국가에 의해 제정됐다 → 국가가 제정했다 / 알고리즘에 의해 결정된다 → 알고리즘이 정한다 |
| ~로 인해/인하여 | ~로, ~때문에 | 그의 죽음으로 인해 → 그의 죽음으로 |
| ~로부터 | ~에서, ~에게서 | 여의도로부터 5km → 여의도에서 5km / 그 사람으로부터 → 그 사람에게서 |
| ~로부터 자유로울 수 없다 | ~를 피할 수 없다 | 죽음으로부터 자유로울 수 없다 → 죽음을 피할 수 없다 |
| ~하기 위해 | ~하려고, ~하려면 | 예약을 하기 위해 전화했다 → 예약하려고 전화했다 |
| ~에도 불구하고 | ~지만, ~는데도 | 여러 번 고쳤음에도 불구하고 → 여러 번 고쳤는데도 |
| ~에서의 | 동사로 풀기 | 2층에서의 살림 → 2층에서 시작한 살림 |
| 관형격 '의' 연쇄 | 동사로 끊기 | 옆집의 인경씨의 개의 목줄 → 이웃집 인경씨가 기르는 개의 목줄 |

## 동사·구문

| 번역투 | 대안 | 예 |
|---|---|---|
| 시간/회의/간담회를 가지다 | 보내다, 열다, 하다 | 즐거운 시간 가지세요 → 즐거운 시간 보내세요 / 회담을 가졌다 → 회담을 열었다 |
| ~을 가지고 있다 | ~이 있다, 서술어로 | 아름다운 목소리를 가지고 있다 → 목소리가 아름답다 / 세 명의 가족을 가지고 있다 → 우리 가족은 세 명이다 |
| 이중 피동 (-어지다 덧붙임) | 단순 피동이나 능동 | 생각되어집니다 → 생각합니다 / 보여집니다 → 보입니다 / 잊혀지다 → 잊히다 / 불리워지다 → 불린다 / 사용되어지다 → 쓰이다 |
| 사물 주어 피동 | 능동으로 | 기회가 주어졌다 → 기회가 생겼다 / 던져진 공은 → 그가 던진 공은 / 노력이 기울여졌다 → 노력을 기울였다 |
| 가장 ~한 것 중 하나 | 그냥 단정 | 가장 흔한 실수 중 하나입니다 → 흔한 실수입니다 |
| ~의 그것 | 생략 | 서울의 공기는 스웨덴의 그것보다 → 서울은 스웨덴보다 공기가 |
| ~하는 중이다 | ~하고 있다 | 사랑하는 중이다 → 사랑하고 있다 |
| ~하지 않으면 안 된다 | ~해야 한다 | 오늘 중으로 하지 않으면 안 된다 → 오늘 안에 해야 한다 |
| 아무리 ~해도 지나치지 않다 | ~해야 한다, 매우 | 아무리 강조해도 지나치지 않다 → 꼭 강조해야 한다 |
| ~에 달하는 | ~에 이르는 | |
| ~을 요하는 | ~해야 하는 | 개발을 요하는 → 개발해야 하는 |
| ~을 돕습니다 (help + -ing) | ~하기 쉬워집니다 | 방문자가 이해하는 것을 돕습니다 → 방문자가 이해하기 쉬워집니다 |
| 명사화 묶음 (진행·처리·수행) | 동사 | 업데이트 진행 후 재시작 처리를 수행해야 합니다 → 업데이트한 뒤 재시작합니다 |

## 낱말

| 번역투 | 대안 |
|---|---|
| 불필요한 복수 '-들' | 생략 (많은 다람쥐들 → 많은 다람쥐) |
| 이는, 이러한 (This, Which) | 이건, 이런, 또는 대상을 직접 쓰기 |
| 핵심을 찔렀다 (hit the nail on the head) | 정곡을 찔렀다, 핵심을 짚었다. 대개는 아예 빼는 것이 낫다 |
| 채우다 (fill in) | 적다, 입력하다 |
| (버그를) 닫다 (close) | 고치다, 없애다 |
| 기능하다 (serve as) | 작용하다, ~ 역할을 하다 |

## 문장부호

- 쉼표: 조사와 어미가 이미 끊는 자리를 표시하므로 한국어는 쉼표가 덜 필요하다. 필요 없는 자리의 쉼표는 지운다.
- 엠대시(—): 쉼표, 괄호, 쌍점, 문장 나누기로 바꾼다.

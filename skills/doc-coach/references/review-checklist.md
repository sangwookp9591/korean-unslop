# 검수 항목

항목마다 "문제 있음"이면 위치(장 번호)와 근거를 적는다. 해당하지 않는 항목은 건너뛴다.

## 공통

**목적과 흐름**
- [ ] 첫 장(또는 요약)만 보고 이 자료가 무엇을 요청하는지 알 수 있는가. 의사결정용이면 결론과 요청이 앞에 있는가. 의사결정용이 아니면 이 순서를 강제하지 않는다.
- [ ] 제목만 이어 읽어도 논리가 이어지는가(목차, 부록, 참고자료 제외)
- [ ] 장과 장 사이에 빠진 단계가 없는가(문제 → 해결 사이에 원인이 없음, 제안 → 요청 사이에 비용·일정이 없음)
- [ ] 같은 메시지가 여러 장에서 반복되지 않는가
- [ ] 한 장에 서로 다른 주장이 둘 이상 섞여 있지 않은가. 한 주장을 받치는 근거 여러 개는 괜찮다.

**근거**
- [ ] 주장마다 근거가 있는가
- [ ] 숫자에 출처, 기준일, 단위, 비교 기준(전년 대비, 목표 대비)이 있는가
- [ ] 가정과 한계, 반대 근거가 필요한 곳에 남아 있는가. 결론 먼저 쓰다가 지워지지 않았는가.
- [ ] 같은 지표가 장마다 다른 값이나 다른 단위로 나오지 않는가

**형식**
- [ ] 시각화가 내용의 관계에 맞는가: 비교는 막대, 추세는 선, 구성비는 100% 막대나 누적 막대, 과정은 흐름도, 일정은 시간축
- [ ] 모든 장이 같은 틀(3분할 박스, 같은 개수의 불릿)로 찍혀 있지 않은가
- [ ] 개조식이 원인, 조건, 책임 주체를 흐리지 않는가. 흐리면 그 줄은 문장으로 푼다.
- [ ] 강조(굵게, 색, 큰 숫자)가 장마다 한두 곳에 그치고 일관된 의미로 쓰이는가
- [ ] 용어와 약어가 처음 나올 때 정의되는가(배포용은 필수)

## 발표용 장표

- [ ] 한 장의 글이 발표자 없이도 다 읽힐 만큼 많지 않은가. 설명은 발표자 노트로 옮길 수 있는가.
- [ ] 발표자 노트가 있는가. 노트가 장표 글을 그대로 되풀이하지 않는가.
- [ ] 발표 시간에 비해 장수가 많지 않은가(대략 1~2분에 한 장. 회사 관행을 따른다)
- [ ] 장과 장을 넘길 때 말로 이을 연결이 노트에 있는가
- [ ] 마지막 장이 질문이나 요청으로 끝나는가("감사합니다"만 있는 장은 요청 장으로 바꾸는 안을 제안)

## 배포용 보고서 (slidedoc 포함)

- [ ] 맨 앞에 요약이 있는가. 요약만 읽어도 결론, 근거 핵심, 요청을 알 수 있는가.
- [ ] 발표자 없이 읽어도 이해되는가. 장표 사이 관계가 문장으로 설명되는가.
- [ ] 표와 차트마다 출처와 기준일이 있는가
- [ ] 목차와 쪽 번호가 있는가(10장 이상)
- [ ] 발표용 장표를 그대로 배포하는 경우, 노트의 설명을 본문으로 옮긴 배포판이나 부록이 있는가

## 출력 (확인할 수 있는 범위만)

- PDF: Read로 페이지 이미지를 보고 글자 잘림, 겹침, 줄바꿈 깨짐, 표가 쪽을 넘어가며 잘린 곳을 확인한다. 텍스트를 뽑았을 때 읽기 순서가 엉키는 곳도 적는다.
- PPTX: 텍스트와 노트만 확인할 수 있다. 글꼴, 줄바꿈, 잘림, 링크는 PowerPoint에서 직접 열어 확인해 달라고 결과에 적는다.
- 가독성: 열람 환경(빔프로젝터, 모니터, 인쇄)에 비해 글자가 작아 보이는 곳, 색으로만 구분한 범례(패턴이나 라벨이 없음)를 적는다. Microsoft PowerPoint 접근성 지침과 Adobe 접근성 PDF 지침을 참고로 든다.

## 🚀 개요

이번 PR은 단순한 버그 수정을 넘어, 결제 모듈의 안정성을 근본적으로 개선하는 중요한 변경사항입니다.

## ✨ 주요 변경사항

- **재시도 로직 도입**: 결제 API 호출 실패 시 지수 백오프(exponential backoff)를 통해 자동으로 재시도가 수행됩니다.
- **멱등성 키 적용**: 중복 결제를 방지하기 위해 멱등성 키(idempotency key)가 적용되었습니다.
- **로깅 강화**: 결제 실패에 대한 상세한 로깅이 추가되어 디버깅이 용이해졌습니다.

## 🔍 테스트

해당 변경사항은 단위 테스트 및 통합 테스트를 통해 철저하게 검증되었습니다. 이를 통해 다양한 엣지 케이스에서도 안정적으로 동작함을 확인할 수 있었습니다.

## 💡 참고사항

다만, 재시도 횟수는 현재 3회로 설정되어 있으며, 이는 향후 운영 상황에 따라 조정될 수 있습니다. 리뷰어분들께서는 특히 멱등성 키 생성 로직에 주목해 주시면 감사하겠습니다.

결론적으로, 이번 변경을 통해 결제 시스템의 신뢰성이 한층 강화될 것으로 기대됩니다. 😊
